# PRD: Тренажёр внутренних состояний «Мысль — Эмоция — Действие»

**Версия:** 2.0  
**Дата:** май 2026  
**Автор:** —  
**Статус:** Draft

---

## 1. Обзор продукта

### 1.1 Описание

Интерактивный веб-тренажёр для самостоятельной работы с внутренними состояниями и автоматическими реакциями на основе модели «мысль → эмоция → действие». Инструмент предназначен для использования как самостоятельно, так и в рамках коучинговых сессий.

### 1.2 Проблема

Менеджеры и сотрудники компаний в условиях давления действуют из автоматических реакций — не осознавая, что именно мысль запускает эмоцию, а эмоция — поведение. Это снижает эффективность решений, качество коммуникации и личный ресурс. Традиционные форматы (книги, тренинги) требуют времени; нужен быстрый и структурированный инструмент для работы здесь и сейчас.

### 1.3 Решение

5–7-минутный цифровой тренажёр, который ведёт пользователя через 4 шага: диагностика состояния → выявление автоматической мысли → замена на более точную мысль → получение персональных рекомендаций. Встроенный ИИ-модуль ускоряет ключевые шаги и снижает когнитивную нагрузку.

## 2. Цели и метрики

### 2.1 Бизнес-цели

- Создать работающий лид-магнит для коуча: тренажёр демонстрирует экспертизу и ценность подхода
- Масштабировать коучинговую помощь без прямого участия коуча в каждом случае
- Сформировать базу лидов через бесплатный доступ к инструменту

### 2.2 Цели пользователя

- За 5–7 минут осознать, какая мысль управляет текущим состоянием
- Получить конкретную альтернативную мысль и первое действие
- Снизить эмоциональную интенсивность ситуации до управляемого уровня

### 2.3 Ключевые метрики (KPI)

| Метрика | Целевое значение |
|---|---|
| Completion rate (прохождение до результата) | ≥ 65% |
| Среднее время сессии | 5–8 минут |
| Снижение веры в старую мысль (самооценка) | ≥ 20% в среднем по сессиям |
| Доля пользователей, использующих ИИ-подсказки | ≥ 40% |
| Повторное прохождение (≥ 2 сессии) | ≥ 30% |

## 3. Аудитория

### 3.1 Основной пользователь

**Менеджеры среднего звена и сотрудники компаний**, которые:

- Испытывают стресс, тревогу или эмоциональное выгорание в рабочем контексте
- Хотят разобраться в ситуации быстро — без долгих сессий и теории
- Не имеют опыта в психологии или коучинге
- Работают в ритме «мало времени, высокие требования»

### 3.2 Вторичный пользователь

**Лайф-коуч** — создатель и распространитель инструмента. Использует тренажёр как:
- Онбординг-инструмент перед первой сессией
- Домашнее задание между сессиями
- Лид-магнит для привлечения новых клиентов

### 3.3 Пользовательские сценарии

**Сценарий A.** Менеджер перед важным разговором с руководителем чувствует тревогу. Открывает тренажёр, за 6 минут понимает, что мысль «меня оценят негативно» не опирается на факты, заменяет её на «я готов и могу ответить на вопросы», делает первый шаг — готовит тезисы.

**Сценарий B.** Коуч отправляет ссылку на тренажёр клиенту накануне сессии. Клиент приходит уже с заполненным разбором — сессия становится глубже и продуктивнее.

**Сценарий C.** Сотрудник в состоянии апатии после неудачного проекта самостоятельно проходит тренажёр, выявляет мысль-катастрофизацию, получает ИИ-подсказки альтернатив и фиксирует одно небольшое действие на сегодня.

## 4. Функциональные требования

### 4.1 Структура и экраны

Тренажёр состоит из 5 экранов (screens) с пошаговой навигацией.

#### Экран 0 — Приветствие и ввод ситуации

- Заголовок, описание цели и формата (5–7 минут)
- Визуальная схема трёх шагов
- Текстовое поле: «Опишите ситуацию, которая вас беспокоит»
- CTA-кнопка «Начать разбор»

#### Экран 1 — Оценка текущего состояния

- Выбор эмоции из сетки (8 вариантов) + поле «другое»
- Шкала интенсивности 1–10 с динамическим бейджем (низкая / средняя / высокая)
- Поле для описания телесных ощущений
- Подсказка: «Тело честнее слов»

#### Экран 2 — Автоматическая мысль и её влияние

- Текстовое поле для автоматической мысли
- ИИ-кнопка «Определить когнитивное искажение» (см. 4.2)
- Поле «Как эта мысль влияет на ваши действия?»
- Шкала веры в мысль (0–100%) — фиксируется как baseline

#### Экран 3 — Замена мысли

- Поле «Новая, более точная мысль»
- ИИ-кнопка «Получить варианты от ИИ» (см. 4.2) с выбором варианта кликом
- Поле «Что меняется в состоянии?»
- Поле «Новые действия»
- Шкала веры в старую мысль (повторно) — для расчёта сдвига

#### Экран 4 — Результат и рекомендации

- Визуальная карта «До / После»: цепочка мысль → эмоция → действие в двух состояниях
- Бар-диаграмма сдвига веры (до и после)
- Персонализированные рекомендации на 24 часа (адаптируются по интенсивности и заполненным полям)
- Итоговая цитата (ротация из 3 вариантов)
- Кнопка «Скопировать результат» (текстовый экспорт в буфер)
- Кнопка «Новая ситуация» (сброс и рестарт)

### 4.2 ИИ-модули

#### Модуль A — Определение когнитивного искажения

**Триггер:** кнопка на экране 2 после заполнения поля автоматической мысли  
**Вход:** текст автоматической мысли  
**Выход:** название искажения + описание (1 предложение) + совет как с ним работать  
**Модель:** claude-sonnet-4-20250514  
**Формат ответа:** JSON `{"distortion": "...", "description": "...", "tip": "..."}`

#### Модуль B — Варианты альтернативных мыслей

**Триггер:** кнопка на экране 3  
**Вход:** ситуация + автоматическая мысль  
**Выход:** 3 альтернативные мысли (до 12 слов каждая), реалистичные, без пустого позитива  
**Модель:** claude-sonnet-4-20250514  
**Формат ответа:** JSON `{"options": ["...", "...", "..."]}`  
**Интеракция:** клик по варианту вставляет его в поле

### 4.3 Навигация

- Прогресс-индикатор (точки с анимацией: неактивная / активная / пройденная)
- Метка текущего шага («Шаг 1 из 3 — Состояние»)
- Кнопки «Назад» / «Вперёд» на каждом экране
- Скролл к верху при переходе между экранами

### 4.4 Экспорт результата

Кнопка «Скопировать результат» формирует текстовый отчёт:

```
=== Разбор внутреннего состояния ===

СИТУАЦИЯ: [текст]

— БЫЛО —
Эмоция: [эмоция] (интенсивность: X/10)
Мысль: [автоматическая мысль]
Действие: [влияние на поведение]
Вера в мысль: X%

— СТАЛО —
Новая мысль: [новая мысль]
Новое состояние: [описание]
Новое действие: [намерение]
Вера в старую мысль: X%

Сдвиг: -X%
```

## 5. Нефункциональные требования

### 5.1 Производительность

- Загрузка интерфейса: < 1 секунды (статический HTML/JS, без внешних зависимостей кроме API)
- Ответ ИИ-модулей: < 5 секунд (индикатор загрузки обязателен)
- Работа без перезагрузки страницы (SPA-логика на vanilla JS)

### 5.2 Совместимость

- Браузеры: Chrome, Safari, Firefox (последние 2 версии)
- Устройства: desktop-first, адаптация для планшета
- Автоматический тёмный / светлый режим через CSS-переменные

### 5.3 Доступность

- ARIA-метки на всех интерактивных элементах
- Скрытый `<h2>` для скринридеров
- Минимальный размер шрифта: 12px
- Контрастность текста: соответствует WCAG AA

### 5.4 Обработка ошибок

- Если ИИ-модуль недоступен — показывать сообщение «Не удалось получить ответ» без блокировки прохождения
- Все поля опциональны — тренажёр работает при минимальном заполнении

## 6. UX и дизайн-принципы

### 6.1 Тон

Дружелюбный, коучинговый, без менторства. Язык от второго лица. Нет осуждения, нет правильных ответов. Подтверждение усилий («Тело честнее слов», «Нет правильного ответа»).

### 6.2 Визуальный язык

- Цветовые акценты по смыслу: фиолетовый — анализ/диагностика, коралловый — проблема/напряжение, зелёный — решение/ресурс
- Карточки с иконками-заголовками для структурирования контента
- Анимированные прогресс-индикаторы
- Бар-диаграммы для визуализации сдвига

### 6.3 Микрокопи

- Плейсхолдеры с конкретными примерами в каждом поле
- Подсказки-инсайты после ключевых вопросов
- Персонализированный итоговый экран с цитатой

## 7. Технический стек

| Компонент | Решение |
|---|---|
| Frontend | HTML + CSS + Vanilla JS (единый файл) |
| ИИ-интеграция | Anthropic API `/v1/messages`, модель `claude-sonnet-4-20250514` |
| Иконки | Tabler Icons (outline, CDN) |
| Хостинг | Любой статический хостинг (GitHub Pages, Vercel, Netlify) |
| Хранение данных | Нет (всё in-memory, сессия не сохраняется) |
| Аналитика | Опционально: Plausible / Umami (privacy-first) |

## 9. Риски и ограничения

| Риск | Вероятность | Митигация |
|---|---|---|
| Пользователь не понимает, что писать в поле «автоматическая мысль» | Высокая | Примеры в плейсхолдере + кнопка «выбрать из списка типичных» (v1.1) |
| ИИ-ответ неточный или нерелевантный | Средняя | Системный промпт ограничивает формат; ответ всегда опциональный, не блокирует прохождение |
| Пользователь остановится на экране 2 (сложный вопрос) | Средняя | Упрощение формулировок, примеры, ИИ-подсказки как снижение барьера |
| Зависимость от Anthropic API (latency, стоимость) | Низкая | ИИ-модули опциональны; тренажёр работает полностью без них |
| Инструмент воспринимается как замена терапии | Низкая | Дисклеймер на стартовом экране: «инструмент для саморефлексии, не медицинская помощь» |

## 10. Открытые вопросы

1. Нужен ли дисклеймер на стартовом экране о том, что инструмент не заменяет терапию?
2. Сохранять ли сессии в localStorage по умолчанию или только по явному согласию пользователя?
3. Какой формат white-label наиболее удобен для коуча — параметры в URL или отдельный конфиг-файл?
4. Нужен ли банк типичных автоматических мыслей менеджеров как быстрый старт?
5. Как измерять реальный поведенческий результат (follow-up опрос через 24–48 часов)?
